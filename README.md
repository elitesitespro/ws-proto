# Workspace

Next.js app with Tailwind CSS, shadcn/ui, and the ReUI registry.

Run the app with `pnpm dev`.

Add shadcn/ui components with `pnpm exec shadcn add button`. Add ReUI items with `pnpm exec shadcn add @reui/c-alert-1`.

The app starts in dark mode. Light mode is also configured through `next-themes`; there is no theme control in the UI.
