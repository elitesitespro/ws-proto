# Currency artwork sources

- Country and European Union flags (`ng`, `us`, `eu`, `bj`, `bf`, `ci`, `gw`, `ml`, `ne`, `sn`, `tg`): [flag-icons](https://github.com/lipis/flag-icons), MIT license in `LICENSE.flag-icons`.
- Bitcoin, Ether, USDC, and Tether icons: [cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons), CC0 license in `LICENSE.crypto-icons`.
- The XOF card combines the flags of the eight countries that use the West African CFA franc. It does not use a single country's flag for the shared currency.
